## 처리 단계와 검증 범위

Google Vision의 글자 추출 뒤 Gemini가 줄 목록을 품목으로 정리하고, 앱이 카테고리와 사전 일치 여부를 확인한다. 화면의 ‘인식오류’는 글자 추출 실패뿐 아니라 사전에 없는 이름이나 원문 근거가 약한 이름에도 표시된다.

이번 변경은 Gemini 품목 정리 프롬프트와 앱 분류 규칙이다. 모델·호출 횟수·재시도·타임아웃은 변경하지 않았다. 프롬프트 길이가 늘어 입력 토큰은 소폭 증가한다.

분류 회귀 테스트는 실제 코드 결과를 검증한다. 기존 Gemini 응답 처리 테스트는 모의 응답을 사용하므로 실제 모델의 인식 정확도를 증명하지 않는다. 배포 후 같은 원본으로 품목 누락, 상품명, 수량, 카테고리를 재확인해야 한다. Vision이 추출하지 못한 글자를 프롬프트만으로 확실하게 복원할 수는 없다.
